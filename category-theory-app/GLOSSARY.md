# 圏論用語集

このアプリで使われる圏論の用語を日本語と英語でまとめました。

## 基本用語

### 圏 (Category / けん)
- **定義**: 対象と射の集まりで、射の合成が定義されているもの
- **例**: ハンバーグメニュー全体
- **記号**: 𝒞, 𝒟 など

### 対象 (Object / たいしょう)
- **定義**: 圏を構成する基本的な「物」
- **例**: ハンバーグ、チーズハンバーグ
- **記号**: A, B, C など
- **補足**: 数学では「もの」と呼ぶこともある

### 射 (Morphism / しゃ)
- **定義**: 対象と対象を結ぶ「関係」や「矢印」
- **例**: 「チーズを乗せる」「ソースをかける」
- **記号**: f: A → B
- **補足**: arrow（矢印）とも呼ばれる

### 射の合成 (Composition / ごうせい)
- **定義**: 複数の射を繋げて1つの射にすること
- **例**: 「チーズを乗せる」→「ソースをかける」= 「チーズを乗せてソースをかける」
- **記号**: g ∘ f または gf
- **読み方**: 「g まる f」または「g コンポーズ f」

### 恒等射 (Identity Morphism / こうとうしゃ)
- **定義**: 何もしない（元のままにする）射
- **例**: ハンバーグ → ハンバーグ（何も加えない）
- **記号**: id_A または 1_A
- **性質**: f ∘ id_A = f, id_B ∘ f = f

## 関手関連

### 関手 (Functor / かんしゅ)
- **定義**: 圏と圏の間の構造を保つ写像
- **例**: ライスセット関手、パンセット関手
- **記号**: F: 𝒞 → 𝒟
- **日本語**: 「監守」という当て字もある（動画より）
- **ポイント**: 対象も射も対応させる

### 共変関手 (Covariant Functor)
- **定義**: 射の向きを保つ関手
- **例**: ライスセット関手（普通の関手）
- **記号**: F: 𝒞 → 𝒟
- **性質**: F(f: A → B) = F(f): F(A) → F(B)

### 反変関手 (Contravariant Functor)
- **定義**: 射の向きを逆にする関手
- **記号**: F: 𝒞^op → 𝒟
- **性質**: F(f: A → B) = F(f): F(B) → F(A)

## 自然変換関連

### 自然変換 (Natural Transformation / しぜんへんかん)
- **定義**: 2つの関手の間の「自然な」対応
- **例**: ライスセット関手 → パンセット関手
- **記号**: η: F ⇒ G
- **ポイント**: 関係性を保ったまま変換する

### 自然性条件 (Naturality Condition)
- **定義**: 自然変換が満たすべき条件
- **意味**: どの順序で操作しても同じ結果になる
- **図式**: 可換図式で表現される
- **例**: 「煮込む→パンにする」=「パンにする→煮込む」

### 成分 (Component)
- **定義**: 自然変換の各対象における射
- **記号**: η_A: F(A) → G(A)
- **例**: 「和風ハンバーグライス定食」→「和風ハンバーグパン定食」

## 高度な概念

### 可換図式 (Commutative Diagram)
- **定義**: どの経路を通っても同じ結果になる図
- **例**:
```
A --f--> B
|        |
g        h
|        |
v        v
C --k--> D
```
h ∘ f = k ∘ g のとき、図式は可換

### 極限 (Limit)
- **定義**: ある図式の「最も普遍的な」頂点
- **例**: 最大公約数、調整役
- **種類**: 積、等化子、引き戻しなど

### 積 (Product)
- **定義**: 2つの対象のペア
- **例**: (A, B)
- **射影**: π₁: A × B → A, π₂: A × B → B

### 余極限 (Colimit)
- **定義**: 極限の双対概念
- **例**: 最小公倍数
- **種類**: 余積、余等化子、押し出しなど

### 随伴 (Adjunction)
- **定義**: 2つの関手の間の特別な関係
- **記号**: F ⊣ G
- **読み方**: 「F は G の左随伴」
- **例**: 自由関手と忘却関手

### モナド (Monad)
- **定義**: 自己関手とその上の特別な構造
- **例**: リストモナド、Maybeモナド
- **プログラミング**: Haskellで重要な概念
- **構成要素**:
  - 自己関手 T: 𝒞 → 𝒞
  - 単位 η: Id ⇒ T
  - 乗法 μ: T² ⇒ T

## 特殊な圏

### 集合の圏 (Category of Sets)
- **記号**: Set
- **対象**: 集合
- **射**: 関数

### 群の圏 (Category of Groups)
- **記号**: Grp
- **対象**: 群
- **射**: 群準同型

### 位相空間の圏 (Category of Topological Spaces)
- **記号**: Top
- **対象**: 位相空間
- **射**: 連続写像

### 前順序集合 (Preorder)
- **定義**: 圏として見た順序集合
- **対象**: 要素
- **射**: a ≤ b のとき a → b

### モノイド (Monoid)
- **定義**: 1つの対象を持つ圏
- **対象**: *
- **射**: モノイドの元

## 重要な性質

### 同型 (Isomorphism)
- **定義**: 逆射を持つ射
- **記号**: f: A ≅ B
- **条件**: f ∘ g = id_B かつ g ∘ f = id_A

### エピ射 (Epimorphism)
- **定義**: 右簡約可能な射
- **例**: 全射
- **性質**: f ∘ g = f ∘ h ならば g = h

### モノ射 (Monomorphism)
- **定義**: 左簡約可能な射
- **例**: 単射
- **性質**: g ∘ f = h ∘ f ならば g = h

### 忠実 (Faithful)
- **定義**: 関手が射を単射的に写す
- **例**: 忘却関手

### 充満 (Full)
- **定義**: 関手が射を全射的に写す

### 本質的全射 (Essentially Surjective)
- **定義**: 各対象が像と同型

### 圏同値 (Equivalence of Categories)
- **定義**: 忠実、充満、本質的全射な関手
- **記号**: 𝒞 ≃ 𝒟

## 図式記法

### ストリング図式 (String Diagram)
- **定義**: 射を線で、対象を線上の点で表す図
- **用途**: 対称モノイド圏での計算
- **例**: カルボナーラのレシピ

### 可換図式 (Commutative Diagram)
- **定義**: 経路が等しいことを視覚的に表す図
- **用途**: 関係の検証

### ペースティング図式 (Pasting Diagram)
- **定義**: 可換図式を繋げたもの
- **用途**: 複雑な関係の表現

## 日常的な言い換え

圏論の概念を日常的な言葉で表現すると：

- **圏**: システム、構造、世界
- **対象**: 物、状態、要素
- **射**: 操作、変化、関係、プロセス
- **関手**: 翻訳、変換、対応付け
- **自然変換**: 自然な置き換え、アップグレード
- **可換図式**: どの順序でも同じ、交換可能
- **極限**: 共通部分、最大公約数的なもの
- **余極限**: 統合、最小公倍数的なもの

## 学習のコツ

1. **具体例から**: まずハンバーグの例で理解する
2. **図を描く**: 視覚的に理解する
3. **関係に注目**: 物そのものより関係性が重要
4. **段階的に**: 圏→関手→自然変換の順に学ぶ
5. **繰り返し**: 何度も読み返すことで理解が深まる
