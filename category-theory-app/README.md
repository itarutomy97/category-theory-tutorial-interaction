# 🍔 圏論を料理で学ぼう！

Category Theory Learning App - インタラクティブな圏論入門アプリケーション

## 概要

このアプリケーションは、数学者・加藤文元先生のYouTube動画「ほぼハンバーグで数学『圏論』を語ります」をベースに作られた、圏論を楽しく学べるWebアプリケーションです。

ハンバーグやカルボナーラなど、身近な料理を使って圏論の基本概念を理解できます。

## 特徴

- 📚 **段階的な学習**: イントロから実践まで5つのレッスン
- 🎨 **視覚的な説明**: SVG図やインタラクティブな要素で直感的に理解
- 🍔 **具体例**: ハンバーグ、カルボナーラ、会社組織など身近な例
- 💡 **クイズ**: 理解度チェックで学習効果を確認
- 📱 **レスポンシブ**: スマートフォンからPCまで対応

## 学習内容

### 1. イントロダクション
- 圏論とは何か
- カルボナーラのストリング図式
- 3つの重要概念の紹介

### 2. 圏（けん）
- 対象と射の基本概念
- ハンバーグメニューで学ぶ圏
- 射の合成
- インタラクティブな図とクイズ

### 3. 関手（かんしゅ）
- 2つの圏の関係
- ライスセット関手の例
- 物と関係の対応
- セットメニューのインタラクティブ体験

### 4. 自然変換
- 関手と関手の関係
- ライスからパンへの変更
- 自然性条件
- 経路比較で理解を深める

### 5. 実践例
- 会社組織での応用
- 最大公約数的な考え方
- モナカとマカロンの類似性
- 様々な分野での応用

## 使い方

### ローカルで実行

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd category-theory-tutorial/category-theory-app
```

2. ブラウザで `index.html` を開く:
```bash
# Macの場合
open index.html

# Linuxの場合
xdg-open index.html

# Windowsの場合
start index.html
```

### 簡易HTTPサーバーで実行（推奨）

Pythonがインストールされている場合:

```bash
# Python 3の場合
python3 -m http.server 8000

# Python 2の場合
python -m SimpleHTTPServer 8000
```

その後、ブラウザで `http://localhost:8000` にアクセス

### Node.jsのhttpサーバーを使用

```bash
npx http-server -p 8000
```

## 操作方法

### ナビゲーション
- **マウス**: 上部のナビゲーションボタンをクリック
- **キーボード**:
  - `→` 次のレッスンへ
  - `←` 前のレッスンへ

### インタラクティブ要素
- **SVG図**: マウスオーバーでツールチップ表示
- **セレクター**: 料理とセットを選んで関手を体験
- **クイズ**: 選択肢をクリックして答えを確認

## 学習のヒント

1. **順番に進める**: イントロから順番に学習することをお勧めします
2. **手を動かす**: インタラクティブな要素を積極的に操作してみましょう
3. **繰り返す**: 一度で理解できなくても、何度も読み返すことで理解が深まります
4. **具体例で考える**: 抽象的に感じたら、ハンバーグの例に戻って考えてみましょう
5. **デベロッパーツールを開く**: F12キーでコンソールを開くと、デバッグ情報が見られます

## カスタマイズ

`css/styles.css` のグラデーション部分を編集:

```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### レッスンの追加
1. `index.html` に新しいセクションを追加
2. `js/app.js` のlessons配列に追加
3. `css/styles.css` で必要に応じてスタイリング
