# 圏論チュートリアル / Category Theory Tutorial

このリポジトリには、圏論を優しく学べる教材が含まれています。

## 📚 コンテンツ

### 🍔 圏論を料理で学ぼう！（インタラクティブWebアプリ）

**ディレクトリ**: `category-theory-app/`

ハンバーグやカルボナーラなど、身近な料理を使って圏論の基本概念を学べるインタラクティブなWebアプリケーションです。

#### 特徴
- 段階的な学習システム（5つのレッスン）
- SVGによる視覚的な図
- インタラクティブな要素とクイズ
- レスポンシブデザイン
- キーボードショートカット対応

#### 学習内容
1. **イントロダクション**: 圏論の基本概念
2. **圏（けん）**: 対象と射、ハンバーグメニューの例
3. **関手（かんしゅ）**: ライスセット関手で学ぶ
4. **自然変換**: ライスからパンへの変更
5. **実践例**: 会社組織、類似性の発見、応用分野

#### 使い方

```bash
# アプリのディレクトリに移動
cd category-theory-app

# ブラウザで開く（方法1: 直接）
open index.html  # Mac
xdg-open index.html  # Linux
start index.html  # Windows

# ブラウザで開く（方法2: HTTPサーバー）
python3 -m http.server 8000
# その後、ブラウザで http://localhost:8000 にアクセス
```

詳しくは [category-theory-app/README.md](category-theory-app/README.md) をご覧ください。

## 🎓 圏論とは？

圏論は「**関係の関係の関係**」を論じる数学です。

### 重要な概念
1. **圏（Category）**: 対象（物）と射（矢印）の集まり
2. **関手（Functor）**: 圏と圏の関係
3. **自然変換（Natural Transformation）**: 関手と関手の関係

### なぜ学ぶのか？
- 抽象的な構造を理解する力がつく
- 様々な分野の共通パターンが見えてくる
- プログラミング（特に関数型）に役立つ
- AI、物理学、認知科学など幅広い応用がある

## 🚀 圏論の応用分野

- 💻 プログラミング（Haskell、関数型プログラミング）

## 📖 学習のヒント

1. **具体例から始める**: まずはハンバーグの例で理解しましょう
2. **図を描く**: 視覚的に理解することが重要です
3. **関係性に注目**: 物そのものより、物と物の関係が大切
4. **段階的に**: 圏→関手→自然変換の順に学びましょう
5. **繰り返し**: 何度も読み返すことで理解が深まります
